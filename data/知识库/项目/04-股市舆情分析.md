# 股市舆情分析 · 基于 BERT 的投资者情绪与股价相关性研究

## 关键信息
- 项目类型：NLP / 量化分析
- 时间：2025年10月 ~ 2025年12月
- 角色：独立完成
- 技术栈：Python（Scrapy、Pandas、NumPy、Matplotlib、Seaborn）、BERT（bert-base-chinese）、Scikit-learn、StatsModels
- 数据规模：3.2 万条股吧评论 + 沪深300指数日线数据

## 背景 (Situation)

在量化投资领域，投资者情绪是影响股价短期波动的重要因素。行为金融学理论认为，社交媒体上的舆论情绪可以作为市场走势的先行指标。但中文金融文本的复杂性（反讽、隐晦表达、行业黑话）使得通用情感分析模型效果不佳，需要针对金融场景进行专门优化。

我希望通过这个项目验证一个假设：**社交媒体上的投资者情绪能否预测股价走势？** 同时锻炼自己在 NLP、数据采集、统计分析方面的完整能力。

## 任务 (Task)

1. 采集东方财富股吧中沪深300成分股的热门评论数据，构建金融舆情数据集
2. 基于 BERT 预训练模型微调中文金融情感分类器，达到 90% 以上准确率
3. 构建日度投资者情绪指数，量化市场乐观/悲观程度
4. 验证情绪指数与沪深300指数收益率之间的统计相关性
5. 分析情绪变化对股价的滞后效应，确定情绪指标的预测窗口

## 行动 (Action)

### 1. 数据采集

- 使用 **Scrapy** 框架爬取东方财富股吧热门股票吧的帖子与评论
- 针对反爬措施（IP 封禁、验证码），实现 IP 代理池轮换 + 请求延迟随机化
- 采集字段：帖子标题、正文、发布时间、阅读量、评论数、股票代码
- 最终采集 **3.2 万条**评论，覆盖 2025 年 6 月至 11 月共 6 个月数据
- 同时从 Tushare 接口获取沪深300指数日线数据（开高低收、成交量）

### 2. 数据清洗与标注

- 去重：URL 去重 + 文本相似度去重（编辑距离），剔除无意义内容（纯表情、纯数字、广告）
- 有效数据 **2.8 万条**
- 人工标注 2500 条样本作为训练集：
  - 正面（1）：看好、买入建议、盈利炫耀
  - 负面（-1）：看空、骂庄家、亏损吐槽
  - 中性（0）：纯信息、无情绪倾向
- 标注策略：两人独立标注 → 交叉验证（Kappa 系数 0.82），不一致样本讨论后统一

### 3. BERT 模型微调

- 基础模型：**bert-base-chinese**（HuggingFace Transformers）
- 训练/验证/测试：8:1:1 划分
- 微调配置：
  - 输入：`[CLS] + 评论文本 + [SEP]`，max_len=128
  - 优化器：AdamW，learning_rate=2e-5
  - batch_size=16，epochs=3
  - 早停策略：验证集 loss 连续 3 轮不降则停止
- 文本预处理：去除 @提及、URL、多余空格，保留中文标点（情感信号）
- 数据增强：随机删除/替换同义词，缓解类别不平衡

### 4. 情绪指数构建

- 每日汇总所有评论的情感分类结果
- 情绪指数公式：`SI = (正面数 - 负面数) / (正面数 + 负面数) × 100`
- SI > 0 表示当日情绪偏乐观，SI < 0 表示偏悲观
- 按成交量加权：高活跃度交易日的情绪信号权重更高
- 生成日度情绪指数时间序列，与沪深300指数对齐

### 5. 统计相关性分析

- **Pearson 相关系数**：情绪指数与次日收益率 r = 0.31（p < 0.01），统计显著
- **Spearman 秩相关系数**：r = 0.28（p < 0.01），验证非线性关系也成立
- **滞后效应分析**：
  - 当日情绪 → 次日收益率：相关性最强（r = 0.31）
  - 当日情绪 → 第 3 日收益率：相关性衰减（r = 0.18）
  - 情绪信号的有效预测窗口约为 1-2 个交易日
- **极端情绪分析**：情绪指数处于前 10% 和后 10% 分位时，次日收益率方向与情绪方向一致率 72%

### 6. 可视化分析

- 情绪指数与沪深300收盘价双轴时间序列图（直观展示情绪 vs 走势）
- 情绪-收益率散点图 + 回归线
- 滞后相关系数热力图（不同滞后天数的相关性矩阵）
- 混淆矩阵 + 分类报告可视化

## 结果 (Result)

### 量化成果

| 指标 | 数值 | 说明 |
|------|------|------|
| 评论采集量 | 32,000+ 条 | 覆盖 6 个月 |
| BERT 情感分类准确率 | **91.2%** | 测试集评估 |
| F1-score（加权） | 0.90 | 三类情感 |
| 情绪-收益率 Pearson r | **0.31** | p < 0.01，统计显著 |
| 极端情绪方向一致率 | 72% | 前/后 10% 分位 |
| 有效预测窗口 | 1-2 个交易日 | 滞后效应分析 |

### 核心洞察

1. **情绪信号有效**：股吧评论情绪与次日沪深300收益率存在统计显著的正相关（r = 0.31），说明散户情绪确实包含信息量
2. **预测窗口短**：情绪信号的有效性在 2 个交易日后快速衰减，适合做短期择时参考
3. **极端情绪更可靠**：当市场情绪极度乐观或悲观时，情绪指标的预测准确率更高（72%），恐慌和贪婪时刻的信号最值得关注
4. **中文金融 NLP 有特殊性**：反讽、隐晦表达（如"利好茅台"）需要领域适配，通用情感模型准确率仅有 78%，微调后提升至 91%

### 项目价值

- 建立了一套可复用的中文金融舆情分析 pipeline（采集 → 清洗 → 标注 → 微调 → 分析）
- 验证了行为金融学中"投资者情绪影响股价"的假设，有实证支撑
- 锻炼了 NLP 模型微调、爬虫工程、统计分析的完整能力

## 面试话术

这个项目是我在学完 NLP 课程后独立做的，叫股市舆情分析，核心是想验证一个假设：**社交媒体上的投资者情绪能不能预测股价走势？**

**数据采集**上，我用 Scrapy 爬了东方财富股吧 3.2 万条评论，同时做了 IP 代理池和请求延迟来应对反爬。数据清洗后有效数据 2.8 万条，人工标注了 2500 条做训练集。

**模型方面**，我用的是 bert-base-chinese 中文预训练模型，在自己的标注数据上做了微调。训练了 3 个 epoch，最终在测试集上准确率 **91%**，F1 也有 0.90。对比之下，没有微调的通用情感模型准确率只有 78%，说明金融领域的文本确实需要专门适配。

**最核心的发现**是，我构建了一个日度投资者情绪指数，然后跟沪深300的收益率做相关性分析。Pearson 相关系数 r = 0.31，p 值小于 0.01，统计上是显著的。而且我发现情绪信号的有效窗口大概在 1-2 个交易日，过了之后相关性就衰减了。另外，在极端乐观或悲观的时刻，情绪指标的方向判断准确率能到 72%。

这个项目让我从数据采集、NLP 模型微调、到统计分析完整走了一遍，也让我对量化金融和 NLP 的交叉领域更感兴趣了。
