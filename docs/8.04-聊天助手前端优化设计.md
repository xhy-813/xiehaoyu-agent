# AI聊天助手前端优化设计文档

> 日期：2026-08-04 | 状态：已确认

## 一、优化范围

保持现有"Dark Geek"暗色极客风格（深蓝底 `#0a192f` + 薄荷绿强调 `#64ffda`），不新增功能，专注体验打磨。

按优先级分四阶段：**视觉 → 动效 → 交互 → 代码整理**。

---

## 二、视觉优化

### 2.1 消息气泡 — 层次感增强

| 项目 | 现状 | 优化后 |
|---|---|---|
| 助手气泡 | 左侧 `2px solid rgba(100,255,218,0.25)` 细线 | 微卡片化：保留强调线，增加极浅渐变底衬 `--msg-assistant-bg`，圆角微调 |
| 用户气泡 | 渐变背景 + 圆角气泡 `border-radius: 18px 18px 4px 18px` | 增加微阴影 `--msg-user-shadow`，发送状态指示 |
| 消息分组 | 每条消息独立间距 `padding: 1.25rem 0` | 同一角色连续消息合并间距（`padding: 0.4rem 0`），不同角色间保留 1.25rem 分隔 |
| 时间戳 | 每条消息都显示时间 | 同组消息只显示首条时间，减少视觉噪音 |

**新增 CSS 变量**：
```css
--msg-assistant-bg: linear-gradient(135deg, rgba(100,255,218,0.03) 0%, transparent 100%);
--msg-user-shadow: 0 2px 12px rgba(100,255,218,0.06);
```

### 2.2 欢迎页空状态 — 氛围感提升

| 项目 | 优化 |
|---|---|
| 背景氛围 | Lottie 头像后方增加柔和径向光晕（`radial-gradient`），与动画状态联动 |
| 标题排版 | 增加场景感引导语，字体层级区分（主标题/副标题） |
| Chip 入场 | 快捷提问 Chip 添加 `stagger` 阶梯入场动画，逐个浮现 |
| Chip 微交互 | hover 时轻微上浮（`translateY(-2px)`）+ 光晕扩散（`box-shadow`） |

### 2.3 内联结果卡片 — 深浅色过渡

| 项目 | 优化 |
|---|---|
| 卡片阴影 | 深色模式用暗阴影，浅色模式用浅阴影，增加 `--result-card-shadow` 变量 |
| 分区头部 | Data/Chart/Trace 分区头部增加图标 + 标签的视觉节奏，间距统一 |
| 图表容器 | 增加最小高度占位（`min-height: 300px`），避免加载闪烁 |
| 折叠面板 | 展开/收起增加 `max-height` + `opacity` 平滑过渡 |

### 2.4 间距 & 排版 & 微交互

| 项目 | 优化 |
|---|---|
| 间距系统 | 统一使用 `0.5rem / 0.75rem / 1rem / 1.25rem / 1.5rem` 五级间距 |
| 行高 | 消息内容 `line-height` 从 `1.75` 调整为 `1.7`，段落间距 `margin: 0.5em 0` |
| 代码块 | 增加语言标签 + 一键复制按钮（见交互优化） |
| 链接 | 增加下划线 hover 动画（`text-decoration` 过渡） |
| 滚动条 | 消息区滚动条更细（`width: 4px`），默认更透明，hover 时显现 |

## 三、动效优化

### 3.1 消息入场

| 项目 | 现状 | 优化后 |
|---|---|---|
| 入场动画 | 统一 `fadeInUp 0.35s` | 首条消息 `fadeInUp 0.35s`，后续消息用更轻的 `fadeIn 0.2s`，避免重复动画疲劳 |

### 3.2 流式打字

| 项目 | 现状 | 优化后 |
|---|---|---|
| 光标样式 | `▊` + `blink 1s` | 改为更细的 `|` + `blink 1s step-end` |
| 光标消失 | 直接移除 `streaming-cursor` 类 | 最后一段文字完成后光标 `opacity` 平滑过渡到 0（`0.3s ease`） |

### 3.3 Tool 状态切换

| 项目 | 现状 | 优化后 |
|---|---|---|
| Tool 切换 | 实时轨迹列表追加，无过渡 | 新增 Tool 标签时 `fadeIn` 轻入场，当前 Tool 指示器增加脉冲动画 |

### 3.4 自动滚动

| 项目 | 现状 | 优化后 |
|---|---|---|
| 跟滚逻辑 | 距底部 100px 内自动跟滚 | 保持不变 |
| 回到底部 | 无 | 增加"回到底部"浮动按钮（仅用户手动上翻 > 200px 时显示），点击后 `scrollTo({behavior:'smooth'})` |

### 3.5 其他动效

| 项目 | 优化 |
|---|---|
| 发送/停止按钮 | 状态切换时 icon 增加微小旋转变换（`transform: rotate(90deg)` 过渡） |
| 内联结果入场 | 图表/数据表卡片展开时增加 `slideDown` 轻动画（`max-height` + `opacity` 过渡） |
| 清空对话 | 消息列表添加 collapse 收缩动画 |

## 四、交互优化

### 4.1 代码块复制

| 项目 | 优化 |
|---|---|
| 复制按钮 | 每个 `<pre>` 代码块右上角增加复制按钮，hover 代码块时显示 |
| 复制反馈 | 点击后按钮变为 ✓ 勾号，1.5s 后恢复 |

### 4.2 停止生成

| 项目 | 优化 |
|---|---|
| 停止后状态 | 已生成内容保留，底部显示"已停止生成"提示 |
| 重试入口 | 停止后可点击重试按钮重新发送上一条用户消息 |

### 4.3 移动端适配

| 项目 | 优化 |
|---|---|
| 标题栏 | 移动端隐藏副标题（`display: none`），标题字号缩小 |
| 输入区 | 减小 `padding`，输入框 `minRows: 1`，`maxRows: 3` |
| 消息列表 | 字体 `font-size` 微调（`0.85rem`），气泡 `max-width` 放宽 |
| 内联结果 | 数据表 `max-height: 200px`，图表 `min-height: 220px` |

### 4.4 键盘操作

| 操作 | 快捷键 |
|---|---|
| 发送 | `Enter`（不变） |
| 换行 | `Shift+Enter`（不变） |
| 清空输入框 | `Escape`（新增） |

### 4.5 错误状态

| 项目 | 优化 |
|---|---|
| 错误提示 | 文案更友好，区分"网络错误"/"AI 服务异常"/"请求超时" |
| 重试按钮 | 更醒目（`border` + `background` 增强），增加重试中 loading 状态 |

### 4.6 消息操作

| 项目 | 优化 |
|---|---|
| 操作按钮 | 始终可见（移动端），桌面端 hover 显示 |

## 六、验收标准

1. 深色/浅色双主题下，消息气泡层次清晰，视觉舒适
2. 欢迎页空状态有氛围感，Chip 有入场动画
3. 内联结果卡片在深浅色下均有良好过渡
4. 流式输出光标平滑，Tool 切换有过渡
5. 用户手动上翻时出现"回到底部"按钮
6. 代码块有一键复制，移动端操作可用
7. 移动端聊天页布局合理，不挤压内容
8. 组件拆分后功能无回归，无 TypeScript 编译错误
