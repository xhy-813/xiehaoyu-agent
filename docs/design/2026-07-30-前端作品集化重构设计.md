## 1. 背景与目标

Xiehaoyu-Agent 当前是一个"登录页 + 聊天页"的工具型前端。本次重构将其升级为**深色极客风单页作品集**（对标 brittanychiang.com v5 布局，视觉细节以参考实现稿为准），AI 问答以 Banner 入口形式放在页面中，点击进入全屏聊天页。

**核心动机**：页面截图将放入简历/作品集（系列图），同时提升面试官现场打开链接时的第一印象。

**成功标准**：

- 每个区块在桌面/移动端截图都"能进简历"
- 面试官无需任何访问码即可体验完整聊天能力
- 聊天全流程（RAG 问答 / ChatBI 出图 / 执行轨迹 / 流式）在 `/chat` 全屏页中完整保留

### 3.4 视觉标志性元素（按参考实现稿）

- **左侧固定栏**：身份 + 横线导航 + 底部社交图标（flex `justify-content: space-between` 竖向铺满）
- **鼠标聚光灯**（brittanychiang v5 招牌，修订 3 新增）：独立 fixed `#spotlight`，`radial-gradient(700px circle at var(--mx) var(--my), rgba(100,255,218,0.22), rgba(100,255,218,0.08) 25%, transparent 65%)`，rAF 节流；无 `mix-blend-mode`；≤980px 与 reduced-motion 下 `display:none`
- **横线指示器**：默认 44px 石板灰；hover/当前项伸长到 70px 并变为亮白 `#e6f1ff`，标签变薄荷绿并右移 4px；「AI 问答」导航项常驻薄荷加粗 + 60px 亮线 + 脉冲圆点
- **滚动侦测**：IntersectionObserver（rootMargin 上 30% / 下 60% 判定带）同步高亮导航
- **章节标题（sr-only）**：修订 3 改为不可见（`clip: rect(0,0,0,0)`），仅供屏幕阅读器与 IO 侦测；原「`01.` 编号大标题」不再在页面正文出现
- **描边胶囊标签**：`rgba(100,255,218,0.08)` 底 + `rgba(100,255,218,0.18)` 描边 + 薄荷字 + 等宽字体；hover 底加深上浮
- **▹ 技能列表**：等宽字体 + 薄荷三角符号前缀
- **hover 浅蓝面板 + group-hover dim**：经历/项目容器 `:hover` 时同级子项 `opacity: 0.5`，被 hover 的子项 `opacity: 1` + 浅蓝底 `rgba(17,34,64,0.5~0.6)` + 微阴影（负 margin 让底色外扩 20px）（修订 3）
- **脉冲圆点**：`pulse-glow` 2s 循环（AI 导航项、Banner badge、聊天页在线状态共用）
- **stagger 入场**：列表子项按 0.08s 阶梯延迟 fade-up

### 4.2 字体

- 正文：`-apple-system, BlinkMacSystemFont, "Segoe UI", "Noto Sans SC", Inter, sans-serif`（系统字体优先，不打包 webfont，不新增依赖）
- 装饰/数字/年份/标签：`"Fira Code", "SF Mono", "Cascadia Code", Consolas, monospace`
- 左栏姓名：`clamp(32px, 4.5vw, 56px)`，字重 700；职位方向 `clamp(16px, 2vw, 22px)` / 500 / 石板灰
- 章节标题：28px / 700 / 亮白；编号 24px / 500 / 薄荷 / 等宽

### 4.3 动效

- 滚动入场：fade-up 28px，`0.7s cubic-bezier(0.16, 1, 0.3, 1)`，IntersectionObserver 一次性触发；`.stagger` 容器子项按 0.08s 阶梯延迟
- 导航：横线 0.3s 伸长过渡；当前区块指示随滚动自动切换
- 卡片/条目：hover 底色与阴影过渡（不位移；Banner 大按钮除外——上浮 3px + 放大 1.03 + 发光）
- 脉冲圆点 `pulse-glow` 2s 循环；Banner 光斑 `float-blob` 8s 漂浮
- 聊天页内部现有动效全部保留（流光轨迹、流式光标、消息入场），配色适配深色
- 滚动行为：锚点跳转 `scroll-behavior: smooth`；全站尊重 `prefers-reduced-motion`

### 4.4 响应式

- 断点：≤1200px（左栏 38% / 右栏 62%）；≤980px（单列，左栏变顶部身份块 + 横向导航行）；≤480px（收窄内边距、经历条目转纵向、技能列表单列）
- `/chat` 全屏页全端可用（≤640px 收窄头部与输入区）

- **Banner 入口**（`/` 的 AI 问答区块）：`ChatSection` 渲染 badge + 标题 + 说明 + 大按钮；点击 `router.push('/chat')`；左栏导航「AI 问答」为锚点项（`#ai-chat`）

- **退出**：返回按钮或 ESC → `router.back()`（无历史时回退到 `/#ai-chat` 锚点）
