## 1. 改造目标

将个人知识库从"通用个人档案"重构为**聚焦求职场景的面试辅助知识库**，使 Agent 在面试场景下能给出更精准、更专业、更有说服力的回答。

### 1.1 核心原则

- **求职导向**：每条内容都必须服务于"让面试官了解我、认可我"这个目标
- **结构化**：每个 `.md` 文件按统一格式编写，确保 RAG 检索片段质量高
- **可维护**：新增/修改某个问题或项目，只需编辑对应文件，重新 ingest 即可
- **口语化**：内容用第一人称口语化撰写，LLM 可直接引用，减少"翻译腔"

### 1.2 改造前后对比

| 维度 | 改造前 | 改造后 |
|---|---|---|
| 目录数量 | 8 个（career/school/work/projects/tech/life/methods/templates） | 5 个（简历/自我介绍/常见问题/项目/工作经历） |
| 内容范围 | 宽泛的个人档案，含生活/方法论等无关内容 | 聚焦求职，仅保留面试相关 |
| 检索精度 | 低，无关内容干扰检索结果 | 高，每条内容都是高质量面试素材 |
| 分类逻辑 | 按内容来源分类（来自哪个目录） | 按面试场景分类（面试官会问什么） |
| 可维护性 | 差，修改一个项目的描述要找多个文件 | 好，一个项目一个文件，一改全改 |

### 2.2 四个分类的设计意图

#### 简历/
- **作用**：Agent 的"事实锚点"。所有关于教育背景、技能清单、实习经历的准确信息都从这里来
- **内容**：完整的简历文本，包含个人信息、教育背景、技能、实习经历、项目经历、获奖情况
- **使用场景**：Agent 被问到任何关于"你是谁"、"你学过什么"、"你有什么技能"时，从简历中检索

#### 自我介绍/
- **作用**：针对"介绍一下你自己"这个高频问题的预置回答脚本
- **内容**：不同长度、不同场景的自我介绍模板
- **使用场景**：Agent 被要求做自我介绍时，直接参考这些脚本，而非从简历中拼凑

#### 常见问题/
- **作用**：覆盖面试中 80% 的高频问题，每个问题有结构化的回答模板
- **内容**：每个文件包含问题分析、回答框架、关键话术、具体案例
- **使用场景**：Agent 被问到匹配的问题时，检索对应文件，结合简历和项目信息生成回答

#### 项目/
- **作用**：每个项目一个独立文件，包含背景、技术栈、成果、面试话术
- **内容**：STAR 法则（Situation-Task-Action-Result）组织，每个项目有可量化的成果
- **使用场景**：Agent 被问到"你做过什么项目"或"详细说说XX项目"时检索

#### 工作经历/（新增，计划外）
- **作用**：详细描述实习经历，比简历中的简短描述更深入
- **内容**：工作概述 + 每个实习岗位的 STAR 法则详述
- **使用场景**：Agent 被问到"你在XX公司做了什么""实习期间最大的收获"时检索

## 3. 内容编写规范

### 3.1 通用格式

每个 `.md` 文件遵循以下结构：

```markdown
# 标题（清晰描述文件内容）

## 关键信息
- 用简洁的列表，列出核心事实
- 每条一行，不超过 20 字
- 方便 LLM 快速提取关键点

## 详细内容
（展开描述，有数字、有细节、有案例）

## 面试话术
（用口语化的第一人称写法，可以直接复制到回答中）
- 先给结论，再展开
- 用数字支撑
- 语气自然，像在聊天
```

## 8. 对部署的影响评估

**结论：不需要 Docker，架构不变。**

| 评估项 | 说明 |
|---|---|
| 外部服务 | 无新增。ChromaDB 仍为嵌入式，BGE 仍为本地模型 |
| 部署脚本 | 需在 `deploy.sh` 中增加 `python -m rag.ingest` 步骤 |
| 数据迁移 | 旧向量库需删除重建（`rag/data/chroma/` 目录） |
| 回滚 | 保留旧向量库备份即可，`ingest.py` 支持幂等重建 |
| 文件体积 | 新增 20 个 `.md` 文件，总计约 50-100KB，可忽略 |

## 9. 后续迭代方向

1. **多轮对话记忆**：Agent 记住之前聊过的项目，不会重复自我介绍
2. **面试模拟模式**：Agent 主动提问，模拟真实面试流程
3. **回答评分**：对每次回答自动评估（有数字+1、有引用+1、有结构+1）
4. **A/B 测试**：同一问题用不同 prompt 生成回答，对比效果
5. **知识库热更新**：修改 md 文件后自动触发 re-ingest，无需手动执行
